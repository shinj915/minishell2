# 🐚 Minishell

> 42 Gyeongsan `minishell` 프로젝트 — 나만의 작은 **bash**를 구현하기.

---

## 📖 프로젝트 개요

**Minishell**은 리눅스의 기본 쉘인 **bash**의 동작 원리를 이해하고,  
직접 커맨드 해석기(shell)를 구현하는 **시스템 프로그래밍 프로젝트**입니다.  
프로세스 관리, 파이프 및 리다이렉션, 시그널 처리 등 **UNIX의 핵심 개념**을 실습할 수 있습니다.

---

## 🎯 목표

- 사용자 입력을 해석하고 명령어를 실행하는 **간단한 쉘 구현**
- **리다이렉션**, **파이프**, **환경 변수**, **시그널** 등 bash 동작 이해
- **프로세스와 파일 디스크립터 관리 능력 향상**
- **시스템 호출 함수(fork, execve, dup2 …)** 숙달

---

## ⚙️ 구현 기능

### 1. 메타문자 처리
- 리다이렉션 `<`, `>`, `>>`
- 히어독 `<<`
- 파이프 `|`
- 환경 변수 `$`

### 2. 빌트인 명령어
| 명령어 | 설명 |
|--------|------|
| `echo [-n]` | 문자열 출력 |
| `cd` | 디렉토리 변경 |
| `pwd` | 현재 경로 출력 |
| `export` | 환경 변수 추가/변경 |
| `unset` | 환경 변수 삭제 |
| `env` | 환경 변수 출력 |
| `exit` | 쉘 종료 |

## 🧠 학습 포인트

- **프로세스 생성 및 제어**: `fork`, `execve`, `waitpid`
- **표준 입출력 리다이렉션**: `dup`, `pipe`, `open`, `close`
- **시그널 처리**: `signal`, `sigaction`
- **문자열 파싱 및 토큰화**
- **메모리 관리** 및 **누수 방지**
